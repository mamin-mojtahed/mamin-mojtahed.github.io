# mamin-mojtahed.github.io

Static site built with Eleventy, HTML, CSS, and JavaScript.

…and some humour

## Local development

Run `npm install` once, then use `npm run dev` for Eleventy’s watched local server. Use `npm run build` to generate `_site/`, and `npm run preview` to serve the production output locally.

The generated site preserves `/`, `/portfolio/`, `/expertise/`, `/network/`, and `/404.html`. GitHub Pages builds and deploys `_site/` through `.github/workflows/pages-deploy.yml`.
